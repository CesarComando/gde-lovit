# «Где ловит» — главный мозг

**Для кого и зачем:** Дайнис (и семья) — понять, в каком месте дома, двора или лагеря лучше ловит мобильный интернет или Wi-Fi. Нажал «Замерить» → приложение меряет скорость и пинг, запоминает место (GPS) и метку → показывает лучшее место и «сколько метров и в какую сторону идти».

**Основа:** сайт без сборки (HTML + JS) + PWA (ставится на экран, работает без интернета), GitHub Pages. Без входа, без базы, без ИИ. Данные только в памяти телефона (localStorage).

## Команды
```
npm test                                   # проверки «сердца» (core.js), без интернета
python -m http.server 8765 --bind 127.0.0.1   # посмотреть на ПК: http://127.0.0.1:8765
```

## Устройство
- `core.js` — «сердце»: расстояние, направление, скорость, группировка замеров в места, CSV. Без окна — проверяется тестами.
- `app.js` — окно: вкладки КАРТА/МЕСТА/ЖУРНАЛ/ЕЩЁ, СКАН (пинг ×3 + 3 короткие загрузки с speed.cloudflare.com, медиана), ПОИСК ∞, «Поиск лучшей точки», ИНС по шагам, локатор (карта Leaflet из `vendor/` или радар), журнал прогулки. Проверка на ПК без GPS: `?demoGeo=широта,долгота`.
- `sw.js` — работа без интернета. **При каждой правке файлов увеличивать VERSION.**

## Правила
- Ничего не отправлять наружу, кроме запроса к speed.cloudflare.com. Никакой статистики, номеров устройства.
- Трафик бережём: замер ограничен по объёму и времени, плитки карты кэшируются (sw.js), счётчик трафика на экране.
- Выкладка на GitHub Pages — только после «да» Дайниса.
- Конец задачи: что сделано → как проверить → что не проверено → один следующий шаг.
