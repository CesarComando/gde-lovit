# Что не проверено (22.11.2026)

- На настоящем телефоне (Android/iPhone) приложение ещё не открывалось: GPS, компас-стрелка, треск, вибрация, «Обход» с включённым экраном, установка на экран.
- Настоящий замер в окне на ПК не прогонялся до конца (снимки экрана делаются в «ускоренном времени»). Логика загрузки проверена отдельно в Node.
- «Точно до бита» — это точный подсчёт: сколько бит реально пришло за время замера. Но сама связь гуляет от секунды к секунде, поэтому два замера в одной точке могут отличаться на 10–30%. Для выбора места это не мешает: сравнивайте места, а не отдельные цифры.
- Силу сигнала в dBm («палочки») браузер не даёт. Для этого нужно отдельное приложение для Android (возможный следующий этап — для поиска зоны в лесу это было бы ещё точнее).
- На iPhone компас включается только после разрешения (спросит при первом СКАНе); тип сети Safari не показывает.
- Отдача (скорость В интернет) не меряется — только скачивание и пинг.
